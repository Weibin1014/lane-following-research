Static, drive-motor-disconnected servo validation only. Original programs remain unchanged.

## Changes

- Preserve v4 ROI55%, HSV masks and sampling heights.
- Require a dark road flank immediately left of a white candidate: at least4 sampled pixels, >=80% HSV V<145 in the6-pixel flank.
- Require >=90% dark pixels inside a proposed yellow/white pair, excluding3 pixels next to each center. These thresholds assume the current dark track and are not general road segmentation.
- Select paired centers as a spatially consistent chain: >=3 levels spanning>=15% image height; gaps<=3 bands; boundary motion<=14% image width per band; farward width increases<=2.5% image width per band. Keep up to4 histories per node and reject similarly scored, separated paths.
- Retain near65% and far55%/60% preview controller unchanged, range330..390. Missing or ambiguous control targets command350; this runner never controls drive throttle.
- Save lossless PNG instead of JPEG, additionally save all unavailable and sign-changing frames, and record pair_status. Fixed-rate snapshots otherwise every0.2seconds.
