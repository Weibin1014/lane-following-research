# S2 image-space preview candidate — 2026-09-07

This is an experimental stationary steering check, not a validated driving controller.

## Evidence

Replayed 233 saved raw JPEG snapshots from ten runs in Downloads (not every captured frame, not independent road scenes). OpenCV 4.9.0, NumPy 1.26.4 on Mac; Raspberry Pi live output can differ slightly. No manual ground-truth center labels or steering-angle measurements.

The current 153630 left-curve scene has near-center error about +0.03 at height 65%, producing PWM349 under the former map. At height55%, its center is left of the near center. The candidate preview error median is -0.1125, giving PWM359 across the seven saved frames. This establishes an earlier left command, not sufficient turning radius.

## Candidate

Keep v4 masks, ROI55%, sampling heights and path selection. Require a valid65% target AND a valid far target (55%, otherwise60%). Use only interpolation bounded to a15%-height gap; no far-only rescue. Uncertain/missing targets produce servo center350.

Let e65 and ef be normalized image offsets. Define trend=(ef-e65)*0.10/(0.65-yfar). Candidate control error=clip(e65+1.5*trend,-1,1). This is an image-space heuristic, not measured curvature or a geometrically calibrated lookahead distance. The gain1.5 is a trial setting selected using these same images and needs fresh validation.

PWM: negative error uses350-40*clip(error/0.5,-1,1); positive uses350-20*clip(error/0.5,-1,1). Range330..390. No throttle control in the new runner. Adafruit board construction initializes board registers/all channels; keep drive motor battery physically disconnected throughout.

## Findings and limits

- Three straight-position sets: all29 saved frames each have near/far targets; median control signs preserved for left/right displacement.
- Two earlier left-curve sets:29/29 each ready, median PWM361.
- Current left-curve set153630:7/7 ready, median PWM359.
- Plain floor:0/29 ready.
- Desktop background:2/29 falsely ready. Background rejection is NOT solved.
- Moving run152620:3/14 ready. Prior target loss near the road edge is NOT solved.
- Run153324:3/9 ready; current controller deliberately does not substitute a far target for a missing near target.
- Extending ROI to40% and sampling farther was rejected: several left-curve scenes selected background/wrong-side centers.
- No right-curve set, metric lane error, closed-loop stability, physical steering angle, or motor interference validation.
