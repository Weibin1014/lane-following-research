# Independent boundary offline comparison

Yellow samples all image rows independently and fits a quadratic curve, while white still uses continuous paths. Estimates center only within observation range; maintains width, dark pavement, and path consistency requirements. Independent estimation is only used for images rejected by the original path scheme. Fitting allows up to 10% outlier rows, retains at least 8 inliers, 20% height coverage, and residuals ≤4 pixels after inlier refitting; these are experimental conditions that have not been independently verified.

The first candidate recovers four final failed frames, but misses the adjacent frame 74; there is a candidate for this frame that clearly deviates from the remaining yellow rows. After outlier row processing, 1352 of the 1432 images were originally valid and remained valid, 3 were restored, 77 were still unavailable, and 29 ground negative samples were still unavailable. The 101 original images saved in the four failed sequences can all be output as targets. This test set participated in the development and is not an independent accuracy evaluation; the real frame-by-frame images are not all saved.

Not yet deployed to drive. The next step is to replay the batch offline on the Raspberry Pi, check the output and delay of 101 pictures, and then decide whether it is necessary to cut off the power and push the collection.
