# White line and local lane width model: offline prototype

Auxiliary estimation is only attempted for current path version unavailable frames, and normal output is retained directly. Each competing white line path must have at least 4 unique yellow-white pairs, covering at least 15% of the image height; fitting the linear relationship between the image row height and the lane pixel width requires that the width increases toward the near and the maximum fitting residual ≤ 3% of the image width. Interpolation is only performed within the observation pairing range, extrapolation is prohibited. Estimated area still checks dark road surface and width range; competing estimates are compared at the same near/far height and rejected if inconsistent. Thresholds are experimental candidates and have not been calibrated by an independent set of truth values.
