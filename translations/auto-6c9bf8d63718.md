Current conclusion: No deployable improvements yet. Continuing the threshold search on the same set of graphs will increase the risk of overfitting. It is necessary to use target positioning error rather than just ready coverage as an evaluation indicator, establish an auditable boundary/center reference on key frames, and evaluate the next model; the current data is sufficient and does not require users to drive or re-acquire.
