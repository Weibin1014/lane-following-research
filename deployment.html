01

BEFORE POWER

Know the build and its limits

This archive documents a 1:16 scale car with a Raspberry Pi, OV5647 CSI camera and PCA9685 controller. The Pi model is not fixed in the research record, so use a board supported by current 64-bit Raspberry Pi OS and the correct CSI cable for that board.

CAMERA160 × 12020 Hz project configuration
CONTROLLER0x40I²C bus 1 · 60 Hz
CHANNELS0 / 1Throttle / steering
RUN LIMIT16 sArchived bounded runner
Calibration rule

The published PWM values describe this car only. They are requested controller counts, not steering degrees or measured speed. Calibrate every different servo, linkage and ESC.

02

OPERATING SYSTEM

Flash the SD card and connect

  1. Install Raspberry Pi Imager and select your Raspberry Pi.
  2. Choose the current recommended 64-bit Raspberry Pi OS.
  3. Set hostname, username, password, Wi-Fi country/network and timezone.
  4. Enable SSH in OS customisation, write the card and let Imager verify it.
  5. Insert the card, power only the Raspberry Pi and wait several minutes.

The examples use username student and hostname lane-car. Replace both with what you entered in Imager.

ssh student@lane-car.local

If local hostname discovery fails, find the Pi's address in the router:

ssh student@192.168.1.123

Update and reboot:

sudo apt update
sudo apt full-upgrade -y
sudo reboot

Reconnect, then shut down before wiring:

sudo shutdown -h now
03

MECHANICAL + ELECTRICAL

Assemble the car and wire PCA9685

  1. Build the chassis and steering linkage following the chassis maker's instructions.
  2. Mount the Pi on standoffs away from moving parts.
  3. Mount the camera level and forward-facing; connect its CSI ribbon while power is off.
  4. Put the car on a stable stand with driven wheels clear of the floor.

Servo power

Use a suitable separate 5–6 V source for the PCA9685 servo rail when required, with a common ground. Verify the labels on the actual board. Do not treat the Pi's 5 V pin as a general servo supply.

04

SOFTWARE

Download and prepare the Pi

cd ~
git clone https://github.com/Weibin1014/lane-following-research.git
cd lane-following-research/beginner-kit
bash scripts/01_prepare_pi.sh

Enable I²C, then reboot:

sudo raspi-config
# Choose: Interface Options → I2C → Yes
sudo reboot

Reconnect and run the read-only check:

cd ~/lane-following-research/beginner-kit
bash scripts/02_system_check.sh
Expected
  • Python imports show PASS.
  • The camera inventory lists a camera.
  • The I²C table shows 40 for the PCA9685.

This check does not initialise PWM.

05

NO PWM

Prove the camera works first

List cameras in an SSH session:

rpicam-hello --list-cameras

Capture one 160×120 JPEG without importing the PWM driver:

cd ~/lane-following-research/beginner-kit
~/lane-env/bin/python scripts/03_camera_capture.py

Copy the result to your computer:

scp student@lane-car.local:~/lane-following-research/beginner-kit/camera-tests/*.jpg .

Check that the track is visible, centred and sharp. Camera height, pitch, lighting and track colour may require vision recalibration.

06

SAFETY GATES

Verify and dry-run the controller

cd ~/lane-following-research/beginner-kit/runner
sha256sum s2_preview_core_local.py

Expected SHA-25695d59d65510ef4596948c277b16e3def86fe404a8aae71b4b4402715b7c1efa8

Run the built-in state checks:

~/lane-env/bin/python v2_local_continuous_16s.py --self-test

Then place the raised car in a normal track-centred pose and run the camera-only default:

~/lane-env/bin/python v2_local_continuous_16s.py
No --drive yet

The default path does not import PCA9685. Review fresh/ready frame counts and saved raw/debug images. If readiness is zero, check camera pose and images before changing thresholds.

07

FIRST PWM

Request neutral, then centre steering

All four must be true

Send the archived stop and centre requests once:

cd ~/lane-following-research/beginner-kit
~/lane-env/bin/python scripts/04_pca_neutral.py --confirm-disconnected

Adjust steering one value at a time. Begin at 365 and move in steps of five:

~/lane-env/bin/python scripts/05_steering_calibrate.py 365 --confirm-disconnected
~/lane-env/bin/python scripts/05_steering_calibrate.py 360 --confirm-disconnected
~/lane-env/bin/python scripts/05_steering_calibrate.py 370 --confirm-disconnected
FunctionChannelArchived request
Throttle stop0370
Throttle forward0400
Steering left / centre / right1440 / 365 / 290

Stop before the linkage strains. If the ESC reacts at the stop request, disconnect its battery immediately and calibrate it.

08

BOUNDED MOTION

Run only after every earlier gate passes

Clear the track, supervise the car directly and keep a physical disconnect within reach. Repeat the self-test and camera-only run before adding --drive:

cd ~/lane-following-research/beginner-kit/runner
~/lane-env/bin/python v2_local_continuous_16s.py --self-test
~/lane-env/bin/python v2_local_continuous_16s.py
~/lane-env/bin/python v2_local_continuous_16s.py --drive

The archived runner asks for interactive confirmations. Its gates include five ready frames, lane-loss stop latching, stale-frame and watchdog checks, and a 16-second time limit.

Optional archived CNN path

The research CNN environment used DonkeyCar 5.3.0, TensorFlow Lite Runtime 2.14.0 and mypilot.tflite. Treat a clean installation on current software as a separate compatibility task.

cd /home/student/projects/mycar
python manage.py drive --model models/mypilot.tflite --type tflite_linear
09

DIAGNOSIS

Stop at the failed stage

No SSH

Confirm Wi-Fi settings and find the Pi in the router, then connect by IP.

No camera

Power down, reseat the CSI cable and verify its connector orientation.

No address 40

Enable I²C and inspect VCC, GND, SDA, SCL and controller power. Do not run PWM scripts.

No ready frames

Inspect the raw/debug frame and normal driving pose before editing thresholds.

Servo strains

Disconnect servo power and inspect supply, linkage, direction and endpoints.

Motor moves at stop

Disconnect the battery and calibrate the ESC. The archived value is not universal.

Safe shutdown

  1. Stop the program with Ctrl+C.
  2. Disconnect motor battery and servo power.
  3. Run the command and wait for SSH to close before removing Pi power.
sudo shutdown -h now
