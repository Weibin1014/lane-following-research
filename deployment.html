03

Run an offline vision test first

The lane-detection program can process an image without importing the PWM vehicle driver.

mkdir lane-following-source
unzip 03-source-code.zip -d lane-following-source
cd lane-following-source
python3 -m venv .venv
source .venv/bin/activate
python -m pip install opencv-python numpy
python python/opencv_lane_detection.py \
  --input /path/to/track-image.jpg \
  --output lane-debug.jpg --no-display

The thresholds were tuned for this project. Different cameras, tracks and lighting normally require recalibration.

04

Prepare Raspberry Pi hardware

The vehicle program expects OpenCV, NumPy, Picamera2 and a PCA9685 at I2C bus 1, address 0x40.

sudo apt update
sudo apt install -y python3-venv python3-opencv \
  python3-numpy python3-picamera2 i2c-tools
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
python -m pip install Adafruit-PCA9685
i2cdetect -y 1
Before vehicle motion

opencv_drive_car.py initializes PWM and can request forward throttle after its three-second countdown. Test the camera and offline detector first. Verify channel mapping, steering centre, stop PWM and direction with drive wheels raised and a physical power disconnect available.

05

Preview or publish the website

Local preview

git clone https://github.com/Weibin1014/lane-following-research.git
cd lane-following-research
python3 -m http.server 8000

Open http://localhost:8000. Stop the server with Ctrl+C.

GitHub Pages

  1. Fork the repository or upload it to a new repository.
  2. Open Settings → Pages.
  3. Choose Deploy from a branch.
  4. Select main and / (root), then save.
  5. Wait for the Pages workflow to finish and use the URL shown by GitHub.
06

Read the evidence limits

  • The public downloads do not include the full thesis.
  • Phone timing was manual and the method order was not randomized.
  • Pixel statistics cover measurable sampled frames, not physical lateral distance.
  • Thresholds and PWM values require calibration before use on different hardware.
