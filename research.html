RESEARCH GUIDE · THESIS COMPANION

The science behind
every recorded lap.

A research-first explanation of how geometric machine vision and CNN imitation learning were implemented, deployed and evaluated on the same 1:16 scale Raspberry Pi vehicle.

Read the contribution ↘Open measured results →
DEFENSIBLE CONTRIBUTION

The work implements a geometric OpenCV controller, deploys a trained CNN predictor and documents a limited system-level comparison on one physical platform.

It does not claim a new neural architecture or general superiority across environments.

03 / INTERACTIVE METHOD

From one frame
to one steering request.

Select a stage to see its role, recorded configuration and connection to the experiment. The diagram describes the tested OpenCV path.

STAGE 01 · SENSOR INPUT

Capture a compact camera frame

The Raspberry Pi camera supplies a 160 × 120 colour image. The small frame limits processing cost and defines the coordinate system used by every later calculation.

Recorded configuration
160 × 120 pixels · 20 Hz
Scientific boundary
A frame is a sensor observation, not an independent measurement of physical lateral position.
See equations and evidence →
IMAGE COORDINATES

Pixels define the reference

The origin is at the upper-left; x increases rightward and y downward. For W = 160, the common image-centre convention is x = 80.

COLOUR SPACE

HSV separates colour roles

Hue represents colour family, saturation its intensity and value its brightness. Fixed ranges produce binary masks that still depend on lighting.

CLOSED LOOP

Actions change future images

A steering request changes the next camera view. Offline detection quality alone therefore cannot establish stable vehicle control.

MEASURED OR OBSERVED
  • Completion of listed laps
  • Manual phone stopwatch times
  • Operator-recorded boundary contacts
  • Logged frame and target availability
  • Reviewed image-space sample coordinates
NOT ESTABLISHED
  • Physical lateral deviation in centimetres
  • Continuous physical vehicle speed
  • Matched camera-to-actuator latency
  • Independent blind ground truth
  • Performance across other tracks and lighting

09 / GLOSSARY

Terms used in
the research record.

Behavioural cloning

Supervised learning that predicts control commands from examples of human driving.

Closed loop

A control process in which each action changes the future sensor observations used by the controller.

HSV

A colour representation separating hue, saturation and brightness for threshold-based segmentation.

I²C

A serial communication bus used here between the Raspberry Pi and PCA9685.

MAE

The mean absolute magnitude of measured errors, reported in pixels for the reviewed image samples.

PWM request

A numerical actuator request. In this study it is not a measured steering angle or vehicle speed.

RMSE

The square root of mean squared error, reported in pixels for measurable sampled frames.

ROI

The selected image region used for road and lane processing.

Stale frame

A camera frame whose age exceeds the controller's accepted freshness threshold.

TensorFlow Lite

A deployment runtime and model format used for the preserved CNN predictor.

Validation loss

Agreement with held-out demonstration targets; it is not a percentage of successful laps.

Watchdog

A separate timing check that requests stopping when control updates do not arrive in time.

No matching term.
